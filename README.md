# Tagada — Studio créatif

Page d'accueil pour Tagada, un studio de fabrication de décors et enseignes sur-mesure basé à Bruxelles.

## Contexte

Traduction d'une maquette Figma (Relume Kit) dans le design system extrait du template Webflow [orange-template.webflow.io](https://orange-template.webflow.io/) : palette, typographie (Archivo / Inter Tight), rayons, easing, et composants (accordéon FAQ à "rideau", menu overlay avec ancres, panneau vidéo type showreel, hover sur les cartes projet).

## Fichier

`index.html` est un fichier autonome — polices et images sont encodées en base64, aucune dépendance externe. Il peut être ouvert directement dans un navigateur ou déployé tel quel sur n'importe quel hébergeur statique (Netlify, Vercel, GitHub Pages, etc.).

## À faire avant mise en production

- Remplacer le panneau vidéo du header (actuellement un placeholder avec bouton play) par le vrai showreel de l'atelier.
- Remplacer les 6 photos du portfolio (actuellement des placeholders architecturaux du kit Figma) par de vraies photos de réalisations Tagada.
- Vérifier les vraies coordonnées de contact (adresse, téléphone, email) avant publication.
